# Входные данные для приёмочной проверки

Маленькие синтетические сценарии около 38°E, 55°N, чтобы ограничения можно было проверять отдельно. Действия, параметры и ожидаемые результаты — в [ручном чек-листе](../../docs/QA_MANUAL_SCENARIOS.md).

| Файл | Назначение |
|---|---|
| `01_basic.geojson` | Квадрат 1 км², одна площадка S |
| `02_no_sites.geojson` | Тот же участок без площадок |
| `03_permanent_zone.geojson` | Постоянный запретный круг радиуса 120 м |
| `04_temporary_zone.geojson` | Полный запрет участка 25.09.2026 09:00–11:00 UTC+03 |
| `05_high_zone.geojson` | Ограничение на высотах 800–2000 м |
| `06_obstacle.geojson` | Вышка 200 м с радиусом 15 м |
| `07_remote_site.geojson` | Единственная площадка на расстоянии 40 км |
| `08_airspace.geojson` | Разрешённая область с потолком 180 м |
| `09_polygon_hole.geojson` | Отверстие 200×200 м в области съёмки |
| `10_invalid_zone_geometry.geojson` | Намеренно неверная зона-точка, QA-B01 |
| `11_empty_site.geojson` | Намеренно пустой Point площадки, QA-B02 |
| `12_polar_terrain.geojson` | Участок около 89°N, вне покрытия ЦМР |
| `13_separate_areas.geojson` | Два отдельных участка |
| `14_unknown_temporary.geojson` | TEMP-зона на всём участке, даты не заданы |
| `15_duplicate_sites.geojson` | Две различные площадки с именем S, QA-B03 |
| `layer_area.kml` | Отдельный слой области 1 км² |
| `layer_zones.kml` | Отдельный слой запретного круга |
| `layer_obstacles.kml` | Отдельный слой препятствия 80 м |
| `invalid_json.geojson` | Намеренно оборванный JSON |
| `params_base.json` | Параметры B для API; **не файл сценария для загрузки в UI** |

Регенерация из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe scripts/qa_acceptance.py --fixtures
```

Генератор детерминированный. Временные ограничения привязаны к 25.09.2026; дата после загрузки в UI выставляется вручную. Ошибочные файлы предназначены для проверки обработки входных данных.
